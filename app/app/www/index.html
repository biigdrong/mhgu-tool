Termux—
先说清代价：手机编译要把 exefs 翻成 C 再用 clang 编译，PC 上是 6 分钟， 手机上通常 40–70 分钟，峰值约需 3 GB 空间，会明显发热。脚本已加 termux-wake-lock， 编译期间别锁屏。
如果你有电脑，用 mhgu-tool 编一次再把 so 拷过来更快：那边用 NDK 的 x86_64 宿主工具链， 手机这边用 Termux 的 aarch64 宿主 clang，两条路产出的 so 等价。
Termux 准备步骤（点开）
1. 装 Termux（F-Droid 版，不要用 Play 商店的旧版）
2. 新建 ~/.termux/termux.properties，写入 allow-external-apps=true，再执行 termux-reload-settings
3. 回到这里点「交给 Termux 编译」，依赖（python / clang / lz4 / unzip）脚本会自己装
4. 编译产物直接写到 /sdcard/MHGU，回来刷新即可看到 






  两条都适用的注意

  · 装好后不要卸载 app，卸载会连 12 GB 游戏文件一起删掉；升级直接覆盖安装。

  · 游戏文件（exefs / romfs）两条支路通用，一份就够，放在 /sdcard/MHGU。

  · 官方版要读这份公共目录，进游戏后用 Plus+Minus 打开设置 → Android 页 → Game files folder 指过去。

  · 中文是 1.4.0 更新自带的官方语言资源，进游戏 Options → Language 选简体中文即可。





  本应用不含任何游戏文件、密钥或游戏代码
